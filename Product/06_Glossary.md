# Glossary

| Term | Definition |
|---|---|
| **Institution** | Umbrella term for University, Education Loan Provider, or Study Abroad Consultancy — any organization that sends invitations to students. |
| **Officer** | An individual user account belonging to an Institution (University Officer, Loan Officer, Consultant). |
| **Student Profile** | The structured record of a student's academics, preferences, documents, and settings. |
| **Profile Completion** | The % of required profile fields filled in; gates search visibility (see `Product/02_Business_Rules.md` rule #4). |
| **Invitation** | A message from an Institution to a Student, always attached to exactly one Offer. |
| **Offer** | The concrete terms bundled with an Invitation (e.g., scholarship %, interest rate, consulting package). |
| **Negotiation** | A one-time student-initiated request to change the terms of an Offer. |
| **Match Score** | The 0–100 AI-generated relevance score between a Student and an Institution/Offer type. |
| **Shortlist** | A saved set of student profiles an officer has flagged from search results. |
| **Saved Search** | A stored set of search filters an officer can re-run without re-entering criteria. |
| **Verification** | The Super Admin review process that confirms an Institution's legitimacy before it can operate on the platform. |
| **Org** | Short for Organization — a University, Loan Provider, or Consultancy account, as opposed to the individual Officer accounts under it. |
| **Subscription Tier** | The paid plan (Starter / Growth / Enterprise) that determines an org's quotas and features. |
| **Audit Log** | The immutable record of state-changing actions, primarily for admin/compliance actions. |
| **Digest** | A batched notification delivery mode (vs. real-time) — see `Modules/08_Notifications.md`. |
